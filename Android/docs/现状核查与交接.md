## 三、本次核查发现的问题（按严重度排序）

### 🔴 1. 单元测试失败，构建门禁是红的 → ✅ 已修复

> 修复方式：`mark()` 先判断末位是不是声调数字（`hasTone`），只有带数字时才 `dropLast(1)`；
> 并补了回归测试 `noToneDigitKeepsWholeSyllable`。**对题库真实数据零回归**——
> 459 个"音节+声调"组合逐一比对，修复前后输出完全一致（因为题库音节全都带数字）。
> 现状：`SearchLogicTest` 14 项 + `PinyinToneTest` 6 项 = **20 项全绿**。

```
PinyinToneTest > neutralTone FAILED
    org.junit.ComparisonFailure at PinyinToneTest.kt:43
19 tests completed, 1 failed
```

**根因**（`util\PinyinTone.kt` 第 22–27 行）：

```kotlin
val tone = when (last) { in '1'..'5' -> last.digitToInt(); else -> 5 }
val body = if (tone in 1..5) syllable.dropLast(1) else syllable   // ← tone 恒在 1..5
```

没有声调数字时 `tone` 被默认成 5，而 `5 in 1..5` 为真，于是 `body` 把**最后一个字母也删掉了**：
`mark("ba")` 返回 `"b"`（应为 `"ba"`），`assertEquals("ba", ...)` 因此失败。

**影响面**：题库里所有音节都带声调数字（声调取值分布只有 1/2/3/4，空字段 0 个），所以**用户可见结果目前是对的**；但测试守卫失效，且"无数字＝轻声"这条注释与实现不符。

**修法**（已实施）：先判断"末位是不是数字"，再决定要不要 `dropLast(1)`。

### 🟠 3. 手机端底部按键文字被裁掉（真实可见缺陷）→ ✅ 已修复（含连带的空白问题）

> **修复内容**（详见 `需求梳理_Android.md` 第 11.5 节）：
> ① 条件区由"按权重撑满"改为"按内容高度收缩"，结果区可见高度 **416dp → 508dp**，中间 128dp 空白消失；
> ② 底部三个按键统一 42dp 高 + 收紧左右内边距 + 单行 + 字号自适应，不再折行被裁；
> ③ 悬浮导航条抬高到系统手势条之上（实测 y 2211 → 2148），平板左侧栏也纳入上下避让；
> ④ 顺带做了 **2 倍系统字号压力测试**，发现并修好了按键与导航文案被截断（「清空当前检」「成语检」）的问题。
> 修复后已在手机 + 平板上用**正式包**重跑全流程并复测坐标、复看截图。

截图 `docs\shots\phone_chengyu_result.png`：「清空当前检索」「清空所有检索」折成两行，第二行被裁。
平板同一界面正常（`docs\shots\tablet_chengyu_result.png`，按钮更宽，单行显示）。

**根因**：`BtnFhlLightSmall` 固定 `android:layout_height=42dp`，而 Material3 按钮默认左右内边距较大；手机上一行三个键各约 130dp 宽，6 个字放不下 → 折行 → 超出 42dp 被裁。
**修法**：这两个键加 `android:paddingStart/End≈8dp`（或 `android:maxLines="1"` + 自适应字号），不要动 42dp 高度。

`项目根目录` 不是 git 仓库，无法 diff / 回滚，接手时只能靠**文件修改时间**推断哪些是后改的。建议先 `git init` 再动优化，否则后面出问题没法比对。

### 🔴 6. `一键重新打包apk.bat` 双击跑不通（收尾时实跑才发现）→ ✅ 已修复

实跑报错：`The system cannot find the path specified.` + `'ause' is not recognized as an internal or external command`。

**根因**：该 `.bat` 是 **LF 换行**（前 16 字节 `40 65 63 68 6F 20 6F 66 66 0A`，71 行全是单独 LF、0 个 CRLF）。
Windows 批处理必须用 **CRLF**，否则 cmd 逐行解析会错位（`pause` 被吃掉了首字母 `p`）。
**这是交付阻断级问题**：你改完 Excel 双击它根本出不了包。

**修法**（已实施）：转成 CRLF（保持无 BOM），实跑一遍 → 题库转换 → 编译 → 复制到 `dist\`，**退出码 0**。
