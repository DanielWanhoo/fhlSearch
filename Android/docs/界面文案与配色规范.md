| 空条件提示 | 请至少填写一个条件 |

> 大标题在 2026-10-15 由"千里寻她"改为"**众里寻他**"（与样例截图一致）。
> **手机版是"整页翻页"**：标题 / 已检索 / 按钮行固定在上方，只有"九种条件 + 匹配结果 + 结果卡片"滚动，检索键固定在底部；
> 检索后自动滚到结果；点「二次检索」若还没挑新条件，会提示并滚回顶部方便挑。平板仍是左右分栏，左条件右结果。

### 5.1 滚轮选项（顺序即显示顺序，v3.2 调整）

| 模式 | 选项 | 排序依据 |
| --- | --- | --- |
| 朝代（15） | 先秦 秦 西楚 汉 三国 晋 南北朝 唐 五代十国 宋 辽 元 明 清 梦 | **历史时间顺序**，非史实的"梦"压最末 |
| 爱好（10） | 博文 品茗 赏玩 食珍 书画 雅宴 演武 弈棋 乐舞 妆饰 | 拼音首字母 A~Z（bo pin shang shi shu ya yan yi yue zhuang） |
| 社团（9） | 百家书院 金戈馆 千工苑 容华社 棠梨坊 饕餮居 无 五湖商社 逸趣社 | 拼音首字母 A~Z（bai jin qian rong tang tao wu wu yi） |
| 品阶（3） | 地 天 玄 | 拼音首字母 A~Z（di tian xuan） |

> 排序是**写死在常量数组**里的，不在运行时按拼音排：同首字母时"短词在前"这类细节能人工确认
> （如 `无` 在 `五湖商社` 前、`棠梨坊`(tang) 在 `饕餮居`(tao) 前），也不引入任何拼音库。
> 只影响**显示顺序**，匹配规则不变（题库朝代实际写作"五代十国（南唐）"，点"五代十国"按包含匹配

## 七、弹窗

名士检索的**三个**窗口都是**屏幕正中的圆角卡片**（不再有底部弹出的面板）：

| 窗口 | 触发 | 实现 |
| --- | --- | --- |
| 滚轮选择 | 点 朝代 / 爱好 / 社团 / 品阶 | `OptionSheetFragment` |
| 输入条件 | 点 职业 / 生逢（生于…）/ 出身-身世 / 技能 / 其他描述 | `InputSheetFragment` |
| 名士详情 | 点检索结果里的任意一行 | `MingshiDetailSheetFragment` |

| 项 | 取值 |
| --- | --- |
| 宽度 | 手机 = 屏幕宽 × 0.86（两侧各留约 29dp）；平板最多 440dp |
| 位置 | 屏幕正中（水平 + 垂直都居中） |
| 背景 | 半透明黑色遮罩，卡片本身是 `bg_fhl_sheet`（宣纸色 + **四个角都是圆角** + 描金边；注意别再只圆上面两个角——那是"底部弹出面板"时代的写法） |
| 关闭 | 点卡片外的空白处 / 返回键；卡片内另有「确定」「关闭」等按键 |
| 实现 | `ui\sheet\CenteredDialogFragment.kt`（三个面板都继承它）+ 主题 `ThemeFhlSearchDialog` |
| 卡片内按键 | 卡片变窄后按键更容易放不下，因此弹窗内的按键一律 `maxLines=1` + 字号自适应（下限 9sp） |
