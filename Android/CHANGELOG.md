# 更新记录

## v1.0.0 — 2026-10-16

首个公开版本。Android 10（API 29）及以上手机与平板可用，完全离线。

### 三大模块

- **成语检索**（山石雅集第 14 题）：319 条成语，拼音 / 声调 / 单字三种模式，各 4 个输入格。
  拼音模糊匹配，声调与单字精确匹配；留空的格子表示"这一位不限"。
  命中的位次会在**成语 / 带调拼音 / 声调**三处同时标绿。
- **诗词检索**（山石雅集第 15 题）：282 条五言诗句，6×5 字格填字，顺序不限，凑成某句诗即命中。
  命中的格子标绿并标上 ①②③④⑤，说明这几个字分别取自哪一格；点结果可切换高亮组合。
- **名士检索**（众里寻他）：115 位名士，9 种条件（朝代 / 爱好 / 社团 / 品阶 / 职业 / 生逢 /
  出身·身世 / 技能 / 其他描述）可叠加筛选；前四种用居中滚轮选择，其余为模糊输入；
  点结果任意一行弹出该名士详情（全部属性 + 题库里属于他的全部相关描述）。

### 检索与层级

- 「检索」在全库查，「二次检索」**在上一次的结果里接着筛，点下去当场出结果**，
  结果标题旁显示"在上一次 N 条结果中筛出"。
- **检索键在首次查出结果后自动收起**（此后接着筛都用「二次检索」，把屏幕让给结果）；
  点「清空所有」、或「清空当前」退到最后一层之下时自动恢复；
  一条都没命中时保持显示，避免条件写错后没法直接重搜。
- 「清空当前」退回上一级时**保留已经填好的条件**，方便在原条件上继续调。
- 没命中的检索不会覆盖候选范围 —— 改完条件可以继续筛，不会出现"怎么搜都搜不出来"。

### 界面

- 中国风配色：宣纸渐变底 + 朱砂主色 + 描金点缀，配色与间距集中写在 `colors.xml` / `dimens.xml`。
- 手机：底部三格导航；平板：左侧竖栏三格导航，各模块改双栏（左条件、右结果）。
- 滚轮选择、条件输入、名士详情三种弹窗统一居中显示，宽度取屏幕 86% 且不超过 440dp。
- 弹窗、卡片、按钮全部圆角；系统的刘海、挖孔、手势条安全区四边都做了避让。

### 适配与体验

- 横竖屏、分屏、平板（`layout-sw600dp`）均有专门版式。
- 系统字号放大到 **2 倍**也不裁字、不重叠（关键按钮开启字号自适应）。
- 软键盘改为 `adjustResize`，输入时不会被键盘挡住；切模块、切模式都不会丢已填内容。

### 工程

- Kotlin + 传统 XML 布局（ViewBinding），刻意不用 Compose，编译快、体积小。
- 检索算法写成纯函数（`logic/SearchLogic.kt`），20 项单元测试直接跑在 JVM 上。
- 题库内嵌为 135 KB 的 JSON，运行时零 IO；`AndroidManifest.xml` **不申请任何权限**，连 `INTERNET` 都没有。
- 所有开发脚本按"脚本所在位置"推算项目根目录，克隆到任何路径都能直接跑。
- 一键打包脚本自动找 JDK、转题库、编译、收产物到 `dist/`。

### 验证

- 单元测试 20 项全绿；资源引用静态校验 600 处全通过。
- Android 17 手机、Android 17 平板、Android 10 手机三台设备，用正式签名包跑通全流程与全部回归脚本
  （检索键显隐、二次检索、字格焦点、弹窗居中、2 倍字号），无崩溃。
