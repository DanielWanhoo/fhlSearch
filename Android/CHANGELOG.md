# 更新记录

## v3.1 — 2026-10-19

**背景**：v3.0 的图片识别在"较复杂的图"上识别率不高（低分辨率小图、带装饰光圈、
被选中的深色圆角格、面板不在左上角的长截图），4 张难点样例只填对 24~29 格，其中一张凑不出诗句。

**改了什么**

- 切格：投影带**中心**拟合成等距点阵后按点阵均分（带子宽窄不可信）；面板点阵少加坐标偏移的 bug 修掉；
  兜底"均分"切出来的格子标记为不可信，只在没有更好选择时使用；
- 取字：极性只看中间 56%、双重阈值、清贴边装饰线、扔与窗口边连通的装饰框、细条墨迹补边、框满时内缩重试；
- 识别：紧/柔/宽**三趟投票**（两趟一致就收工），票数相同比置信度；
- 繁体归简：新增 `T2S.kt`（768 对，自动生成），ML Kit 吐繁体时不再让整句检索落空；
- 一个字的宽度被读成好几个字时只算一格，其余进"候选"；
- **按题库补救**：一条诗句都没命中时，看哪句诗的 5 个字有 4 个确实在格子里且唯一，
  就补上缺的那个字再检索，并提示"识别可能有误…请对照截图核对"；分不开就不猜。

**效果**：6 张样例图**全部 30/30 填满、全部直接给出诗句**（v3.0 是 5/6）。

**其它**：版本号 3.1（versionCode 4）；单元测试 24 项；`tools/test_ocr.py` 修掉"应用未安装时
先 run-as 建目录导致全部 ENOENT"的顺序 bug。

## v3.0 — 2026-10-19

诗词检索支持**拍照 / 相册导入自动识别**，并加了**信息面板**；版本号跳到 3.0（与 Windows 端的功能演进对应）。

### 新增：图片识别（诗词检索）

- 字格下方新增 **拍照识别** / **相册识别**：把带 6×5 字格的题目截图或照片丢进去，
  程序自动找出字格、认出 30 个汉字填进格子，并**直接开始检索**（不用再点「开始检索」）。
- 识别流水线：按 EXIF 摆正 → 找亮底面板（面板 / 整图各试一次）→ 暗像素投影切 6 列 5 行 →
  **逐格**判极性、拉对比、裁墨迹、放大、锐化 → 拼成白底大图 → ML Kit 中文识别 →
  按包围盒坐标映射回格子 → 第一趟没填满就换"原图风格"再认一遍取并集。
- 识别引擎用 **ML Kit 中文（内置模型版）**：模型随 apk 安装，**离线、不依赖 Google Play 服务、不下载模型**，图片不出手机。
- **新增权限：0**。拍照走系统相机（`TakePicture` + `FileProvider` 授权的缓存文件），选图走系统照片选择器（`PickVisualMedia`）。
- 认错的字可以直接改；没凑出诗句时会提示"识别结果可能有错，对照截图改一下再检索"。
- 实测 6 张样例图（手机拍照、小红书长截图、504×393 小图）：**5 张直接出诗句**，填充 27~30 / 30 格。
  同一批图在 Windows 端（Windows.Media.Ocr）有 3 张没认全、凑不出诗句 —— 换 ML Kit 后更准。

### 新增：信息面板

- 每个页面**大标题右边**新增 ⓘ 图标，点开是屏幕正中的信息卡片：软件名、**版本号（从安装包读）**、
  题库条数（成语 319 · 诗词 282 · 名士 115）、三大模块用法、图片识别怎么拍、题库来源与版权、隐私说明。
- 滚动区高度按屏幕 45% 封顶，标题与关闭键始终可见；点「关闭」或卡片外空白处收起。

### 工程

- `versionCode 3` / `versionName "3.0"`。
- `ndk.abiFilters` 只保留 `arm64-v8a` / `armeabi-v7a` / `x86_64`（砍掉 32 位 x86，省 11 MB）。
- 安装包从 12.6 MB 涨到 **44.25 MB** —— 主要是 ML Kit 的识别库（每 ABI 约 10 MB）与中文模型（约 2.5 MB）。
- 新增回归脚本：`test_ocr.py`、`test_ocr_gallery.py`、`test_info.py`；
  三台设备（Android 17 手机 / 平板、Android 10）用正式包全部通过，单元测试 20 项、资源校验 600 处引用依旧全绿。

## v1.0.0 — 2026-10-16

首个公开版本。Android 10（API 29）及以上手机与平板可用，完全离线。

### 三大模块

- **成语检索**（山石雅集第 14 题）：319 条成语，拼音 / 声调 / 单字三种模式，各 4 个输入格。
  拼音模糊匹配，声调与单字精确匹配；留空的格子表示"这一位不限"。
  命中的位次会在**成语 / 带调拼音 / 声调**三处同时标绿。
- **诗词检索**（山石雅集第 15 题）：282 条五言诗句，6×5 字格填字，顺序不限，凑成某句诗即命中。
  命中的格子标绿并标上 ①②③④⑤，说明这几个字分别取自哪一格；点结果可切换高亮组合。
- **名士检索**（众里寻他）：115 位名士，9 种条件（朝代 / 爱好 / 社团 / 品阶 / 职业 / 生逢 /
  出身·身世 / 技能 / 其他描述）可叠加筛选；前四种用居中滚轮选择，其余为模糊输入；
  点结果任意一行弹出该名士详情（全部属性 + 题库里属于他的全部相关描述）。

### 检索与层级

- 「检索」在全库查，「二次检索」**在上一次的结果里接着筛，点下去当场出结果**，
  结果标题旁显示"在上一次 N 条结果中筛出"。
- **检索键在首次查出结果后自动收起**（此后接着筛都用「二次检索」，把屏幕让给结果）；
  点「清空所有」、或「清空当前」退到最后一层之下时自动恢复；
  一条都没命中时保持显示，避免条件写错后没法直接重搜。
- 「清空当前」退回上一级时**保留已经填好的条件**，方便在原条件上继续调。
- 没命中的检索不会覆盖候选范围 —— 改完条件可以继续筛，不会出现"怎么搜都搜不出来"。

### 界面

- 中国风配色：宣纸渐变底 + 朱砂主色 + 描金点缀，配色与间距集中写在 `colors.xml` / `dimens.xml`。
- 手机：底部三格导航；平板：左侧竖栏三格导航，各模块改双栏（左条件、右结果）。
- 滚轮选择、条件输入、名士详情三种弹窗统一居中显示，宽度取屏幕 86% 且不超过 440dp。
- 弹窗、卡片、按钮全部圆角；系统的刘海、挖孔、手势条安全区四边都做了避让。

### 适配与体验

- 横竖屏、分屏、平板（`layout-sw600dp`）均有专门版式。
- 系统字号放大到 **2 倍**也不裁字、不重叠（关键按钮开启字号自适应）。
- 软键盘改为 `adjustResize`，输入时不会被键盘挡住；切模块、切模式都不会丢已填内容。

### 工程

- Kotlin + 传统 XML 布局（ViewBinding），刻意不用 Compose，编译快、体积小。
- 检索算法写成纯函数（`logic/SearchLogic.kt`），20 项单元测试直接跑在 JVM 上。
- 题库内嵌为 135 KB 的 JSON，运行时零 IO；`AndroidManifest.xml` **不申请任何权限**，连 `INTERNET` 都没有。
- 所有开发脚本按"脚本所在位置"推算项目根目录，克隆到任何路径都能直接跑。
- 一键打包脚本自动找 JDK、转题库、编译、收产物到 `dist/`。

### 验证

- 单元测试 20 项全绿；资源引用静态校验 600 处全通过。
- Android 17 手机、Android 17 平板、Android 10 手机三台设备，用正式签名包跑通全流程与全部回归脚本
  （检索键显隐、二次检索、字格焦点、弹窗居中、2 倍字号），无崩溃。
