## 一、项目目标

做一个 **Windows 免安装绿色小工具**，把《忘川风华录》"山石雅集"活动里的三类检索题，做成一个能离线快速查答案的程序。

| 模块 | 大标题 | 作用 |
| --- | --- | --- |
| 成语检索 | 山石雅集第 14 题 | 按拼音 / 声调 / 单字筛 4 字成语 |
| 诗词检索 | 山石雅集第 15 题 | 从 6×5 字格里挑 5 个字拼出诗句 |
| 名士检索 | 千里寻她 | 按 9 个维度层层筛出是哪位名士 |

**硬性约束**

1. 免安装：单个 exe，双击就能跑，不写注册表、不装东西。
2. 最低支持 **Windows 7**，向上兼容 Win8 / 8.1 / 10 / 11。
3. 界面优先考虑各版本 Windows 的兼容性。
4. 整体中国风配色与视觉。
5. 三大模块用**左侧边栏**切换，主界面**分栏**。

## 四、模块一：成语检索（山石雅集第 14 题）

### 4.1 题库实测

文件：`data\成语检索.xlsx`（工作表 `Sheet1`）

实际清点：**319 条成语**，13 列。

| 列 | 含义 | 示例 |
| --- | --- | --- |
| A | 成语 | 暗渡陈仓 |
| B–E | 拼音 ①②③④（无声调小写） | an / du / chen / cang |
| F–I | 单字声调 ①②③④（阿拉伯数字） | 4 / 4 / 2 / 1 |
| J–M | 单字 ①②③④ | 暗 / 渡 / 陈 / 仓 |

- 319 条全部 4 字，无重复。
- 声调取值只有 `1 / 2 / 3 / 4`。
- 单字列与成语逐字完全一致，校验通过。

### 4.2 三种检索模式

模式用**选项卡**切换：`拼音` / `声调` / `单字`。下方固定 **4 个输入框**，分别对应成语的第 1、2、3、4 个字。

**① 拼音模式（模糊）**

- 输入：英文字母，1–6 位。出现非字母 → 输入框变红 + 提示"**非法字符**"。
- 匹配规则：输入内容是某字拼音的**连续子串**即算命中。
  - 输入 `zh` → 命中 `zhu` `zhong` `zhen` …
  - 输入 `ang` → 命中 `cang` `chang` `shang` …
  - 输入 `an` → 命中 `an` `cang` `chan` …
- 空着的输入框 = **该位置不限**。
- 匹配大小写不敏感（题库里 `Shuang`、`Zhi` 这种大写也能命中）。

**② 声调模式**

- 输入：单个阿拉伯数字 `1`–`4`。其他字符 → 红框 + "**非法字符**"。
- 匹配规则：精确相等；空 = 不限。

**③ 单字模式**

- 输入：单个汉字。非汉字 → 红框 + "**非法字符**"；连打多个汉字只保留第一个。
- 匹配规则：精确相等；空 = 不限。

**关于"切换模式保留输入内容"的实现方式**

- 三种模式**各自记住自己最后一次填的内容**。
- 切到某个模式时：恢复该模式上次填的内容（首次进入为空）。
- 这样既不会丢内容（切回拼音，"an" 还在），也不会出现"把拼音字母留在声调模式里报非法"的尴尬。
- 每个输入框右侧自带一个小 `✕` 按钮，方便单独清掉一格。

### 4.3 检索 / 二次检索的层级逻辑

程序内部维护一个"检索层级栈"：

```text
初始态(第0层)  ──首次检索──▶  第1层结果  ──二次检索──▶  第2层结果 ──▶ …
```

- **检索**：用当前输入框的条件筛选。第 0 层时在全部 319 条里筛；已经有结果时，在**上一层的结果里**筛。
- **二次检索**（结果区按钮）✅ 已确认：**清空当前模式的输入框**，并进入"在当前 N 条结果中继续筛"的状态——输入区上方出现提示条 `二次检索中 · 当前范围：N 条`。你换模式、填新条件，再点"检索"，就在这 N 条里缩小范围。
- **清空当前检索**：丢掉当前层结果，退回上一层（第 1 层退回初始态），输入框清空。
- **清空所有检索**：直接回到初始态：输入框全清、模式回到"拼音"、层级栈清空。
- 若输入框**全部为空**就点"检索"：提示"请至少填写一个条件"，不执行检索。

### 4.4 结果展示与绿色标注

- 每条结果一行，展示三样：**成语（4 字）** + **拼音（4 个音节）** + **声调（4 个数字）**。
- **绿色标注**：你当前输入框里**填了内容的那几位**，在"汉字 / 拼音 / 声调"三处**同时标绿**（浅绿底 + 深绿字）。
  - 例：拼音模式下只在第 2 格填了 `du` → 结果里每个成语的第 2 个字"渡"、拼音 `du`、声调 `4` 都标绿。
- 结果区顶部显示：`共 N 条结果 · 当前第 N 层`。
- 结果 ≥ 2 条时排序（第 1 字拼音升序）。

### 4.5 按钮出现规则

| 结果情况 | 出现的按钮 |
| --- | --- |
| **≥ 2 条** | 清空所有检索 · 清空当前检索 · 二次检索 |
| **= 1 条** | 清空所有检索 · 清空当前检索 |
| **= 0 条** | 显示"**未检索到对应结果**"，按钮：清空所有检索 · 清空当前检索 |

## 五、模块二：诗词检索（山石雅集第 15 题）

### 5.1 题库实测 ✅ 已确认为 `诗词检索.xlsx`

文件：`data\诗词检索.xlsx`（工作表 `择字成诗`）

- **282 条诗句**，全部 5 个字，无重复。
- 字段：`诗句` / `诗词名` / `作者` / `①` `②` `③` `④` `⑤`（逐字拆开）。
- 覆盖 **132 个诗词名**、**37 位作者**。
- 其中 **15 条含重复字**（如"处处闻啼鸟""离离原上草""一岁一枯荣""射人先射马""青青园中葵"），程序按"重复字需要两个格子"处理。

### 5.2 字格与输入 ✅ 6 列 × 5 行

- 字格：**6 列 × 5 行 = 30 格**，每格 1 个汉字。
- 字格下方**常驻**：`清空` 键、`检索` 键。
- 每格只能放 **1 个汉字**：
  - 输入多个汉字 → **只保留第一个**
  - 输入非汉字（字母、数字、标点）→ 提示"**非法字符**"
  - 允许留空格子（空格子不参与匹配）
- 选中格子：用**红色方框**高亮（2 px 朱砂红）。
- **键盘方向键 ↑ ↓ ← →** 移动选中格；鼠标点击也能选中；按 `Backspace` / `Delete` 清空当前格。
- `清空` 键：清空全部 30 格，回到初始状态。

### 5.3 匹配算法

1. 收集字格里所有已填汉字，形成一个"字库"（记录每个字出现在哪些格子）。
2. 遍历 282 条诗句，判断它的 5 个字能不能**各用一个不同的格子**凑齐（诗句里有重复字，就需要字格里也有两个相同的字）。
3. **与字格里的排列顺序无关**——这正是需求里说的"最终的诗词句不一定在表格中按照原顺序呈现"。
4. 命中后在每个用到的格子上标一个**序号 ①②③④⑤**，让你一眼看出答案是怎么拼出来的。

### 5.4 结果展示 ✅ 全部列出 + 点选高亮

- 命中格子用**绿色方框**标亮。
- 下方列出所有命中的诗句：**诗句** + **《诗词名》** + **作者**。
- **点选某一条**，字格上就只高亮组成它的那 5 格（并显示顺序序号）；默认自动选中第一条。
- 一条都没命中 → 提示"**未找到可组成的诗句**"，并给出 `清空` 键。

模式以**左侧竖排列表**呈现（避免图标挤占空间）；点开某个模式后，右侧出现对应的**菜单选项卡**或**输入框**。

| **社团** | 菜单选项卡（9 项，单选） | 百家书院、千工苑、金戈馆、容华社、棠梨坊、饕餮居、五湖商社、逸趣社、无 |

### 6.3 模糊检索规则

1. **归一化**：把"检索词"和"候选文本"都先去掉所有非汉字字符（标点、数字、字母、括号、换行、空格等），只留汉字。
2. **连续子串匹配**，**不拆分检索词**：
   - 搜 `乱世` → 命中 `乱世`、`生于乱世`、`乱世/王朝更迭`
   - 搜 `作 画` → 去空格后等同 `作画`
   - 搜 `乱 世` → 去空格后等同 `乱世`，仍然能命中

### 6.4 检索结果、按钮与计数

| 结果情况 | 展示内容 | 按钮 |
| --- | --- | --- |
| **1 条** | `名士（朝代）`，如 `嬴政（秦）` | 清空所有检索 |
| **≥ 2 条** | 全部列出，格式同上 | 清空所有检索 · 返回上一级检索 · 二次检索 |
| **0 条** | "**未检索到该名士**" | 清空所有检索 |

- **检索次数计数**：界面上固定位置显示 `检索次数：N`，每点一次"检索"+1，点"清空所有检索"归零。
- **二次检索**保留已有结果作为筛选范围；**切换检索模式不清空已有结果**（需求第 9 条明确要求）。
- 按钮命名按需求原文：名士模块用"**返回上一级检索**"（与成语/诗词模块的"清空当前检索"是同一个逻辑）。
- 结果列表每行右边有个小 `复制` 图标，方便你把"嬴政（秦）"复制出去。

### 12.2 错位 / 遮挡 / 残影的根因与修复

查出**三个独立原因**，都修掉了。

**原因一（残影的真正元凶）：`MainForm` 漏了 `ControlStyles.ResizeRedraw`**

窗口缩放时，WinForms 默认只重画"新露出来"的那一条区域，**不重画整个客户区**。
而界面上有一批**右对齐**的文字（顶部题库统计、模块标题栏的检索次数、状态栏的检索次数），
每改变一次窗口宽度，右对齐位置就变一次；旧的没被擦掉，新的又画上去 ——
连续拖拽后就是**同一段字在好几个位置叠出来的"字符残影"**。

这正好解释了那些看似无意义的碎片：`5 · 5 5`、`} } : 0 0`、状态栏的 `0 0 1 0 0`。

修法：

- `MainForm` 补上 `SetStyle(... | ControlStyles.ResizeRedraw | ...)`
- `OnResize` 里再显式 `Invalidate()` 一次（双保险）
- `PersonDetailForm` 同样补上

**原因二：透明 Label 与自绘背景互相干扰（文字发花）**

界面上原来有一批 `BackColor = Color.Transparent` 的 Label（状态栏 2 个、各模块信息行 4 个、
名士的条件标题和提示 2 个）。WinForms 绘制这类 Label 的背景时，会**回调父容器的 `OnPaint`**
去"透出"父背景；而父容器本身就是全自绘的，两边互相触发，也会加剧花屏。

修法：**全部删掉透明 Label，改由父容器自己绘制文字**：

| 位置 | 现在由谁画 |
| --- | --- |
| 状态栏左右两段文字 | `MainForm.OnPaint` |
| 各模块结果区顶部统计 | 卡片 `CardPanel.Paint` → `PaintResInfo` |
| 名士「【朝代】条件」+ 提示语 | 卡片 `CardPanel.Paint` → `PaintCondText` |

**原因三：选项卡会偷偷改自己的高度（错位、按钮被挤走）**

`ChipStrip.Relayout()` 里原本有一句 `Height = 需要的高度`。父容器按算好的位置放好提示文字
和「检索」按钮之后，选项卡又把 Height 撑大，于是**压住提示文字、把按钮挤出可视区**。

修法：

- `ChipStrip` 不再修改自己的高度，改为提供 `MeasureHeight(width)`，由父容器决定给多高
- 成语模块：选项卡 → 输入框 → 检索按钮**从上往下顺序排**，高度不够就压低选项卡
- 名士模块：条件区同样顺序排；**9 个模式按钮在窗口不够高时自动转成两列**（5 行），
  保证条件区至少能分到约 3 行选项卡的高度
- **选项卡本身支持滚动了**（放不下的行用滚轮或右侧细滚动条翻），所以选项永远不会"点不到"；
  高度只取整行倍数，不会出现"半行被切掉"的难看样子
- Windows 的 `WM_MOUSEWHEEL` 只发给**有焦点的**控件，所以 `CardPanel` 会按光标位置
  把滚轮转发给选项卡（否则光标停在上面滚也没反应）
