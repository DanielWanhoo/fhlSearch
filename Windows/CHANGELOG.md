# 更新记录

## v3.1.0 — 2026-10-19

**大幅提升「从图片识别」的识别率。** 用一批真实截图回归，30 格全对的图片从 2/6 提升到 4/6，
能直接命中诗句的从 3/6 提升到 5/6，原本完全认不出网格的那张也能用了。

### 识别率

- **面板检测不再"一裁到底"**：面板和整图各算一遍，谁能切出 5 行 6 列就用谁。
  之前面板一旦裁歪（截图里有大片深色区域就会发生），整张图直接判"找不到字格"
- **逐格归一化**：按每个格子**自己的底色**判断字比底深还是浅，
  深底浅字会自动反相；再按 2% / 98% 分位拉对比度。
  之前是直接把原图贴进拼板，深色格子等于给 OCR 一块黑板
- **放大 + 锐化**：每格放大到 240px（原 190px），归一化版再过一道反锐化，细笔画更清楚
- **两种拼板取并集**：归一化版和原图版各有各认不出的字，第二趟只在第一趟还有空格子时才跑，
  所以干净的截图仍然只跑一趟（约 1 秒），难认的图才多花不到 1 秒
- 修了一个坐标 bug：识别结果用的是包围盒**左上角**去和格子中心比距离，
  格子放大后会把词判到范围外（表现为"OCR 认出了 30 个词，却一格都没填上"）

### 交互

- 识别完如果**拼不出诗句**，会弹窗提示"多半是个别字认错了，请检查字格后手动修改"，
  不再是默默显示"未检索到"

### 文档

- 使用说明新增「**识别不准时怎么办**」和「**截图建议**」两节，
  并附上标准样例截图（`docs/screenshots/07-ocr-sample.jpg`）
- **程序内「使用说明」对话框补上了 OCR 说明**（以前只有 `docs/使用说明.md` 里有，
  点程序里的「使用说明」看不到），并新增「**查看截图样例**」按钮：
  点开就能看到那张理想输入截图（图片内嵌在 exe 里，不破坏单文件）
- `dist\使用说明.txt` 的生成修了两处排版：
  引用块的 `> ` 前缀、图片的 `![..](..)` 语法不再原样漏进纯文本；
  图片位置改成一句「在程序里点『使用说明』→『查看截图样例』可看到原图」

### 兼容性说明

- 文档补充 **Windows on Arm（ARM64）** 的可行性论证与结论：
  Windows 11 Arm 版可运行（原生 Arm64 或 x64 仿真），Windows 10 Arm 版不保证。
  论证基于 PE/CLR 头实测（`COR Flags` 只有 `MH_ILONLY`，无 `32BITREQUIRED` / `32BITPREFERRED`）、
  无原生依赖、平台侧对 Arm64 .NET Framework 与仿真能力的支持，写入
  `docs/技术说明.md`、`docs/使用说明.md`、`README.md` 与程序内「使用说明」
- 明确标注这是**基于二进制的推导，未做 Arm 实机测试**，并给出三条自验方法

### 已知限制（已写进使用说明）

- 格子里的字实际高度低于约 40 像素（缩略图、模糊图）时识别率明显下降
- 微信 / QQ 二次压缩过的图片、拍屏反光严重的照片，识别率会掉
- 极个别的字仍可能认错 —— **改掉那一个字再检索即可**，不影响使用

## v3.0.0 — 2026-10-19

诗词检索加入**从图片识别**：直接丢题目截图，自动认出 6×5 字格里的 30 个字并自动检索。

### 新增

- 诗词检索底部新增「**从图片识别**」按钮，支持 `png / jpg / jpeg / bmp / gif / tif / tiff`
- 自动**找出图里的 6×5 字格**（先裁亮色面板忽略黑边、状态栏，再用暗像素投影切格），
  不需要用户事先裁剪
- **逐格抠图放大、拼成白底大图**再交给系统 OCR —— 整图直接识别会把相邻字连读、
  把单字误读成标点（30 格只能认出 18 格），拼板后两张样图都是 **30/30**
- 识别结果按包围盒中心**映射回对应格子**，填好后**自动开始检索**
- 图片过大时自动等比缩小（最长边 2400），避免慢和内存吃紧
- 新增命令行模式 `fhlSearch.exe --ocr 图.png 输出.txt`，方便排查某张图为什么认不出

### 系统要求（新增）

- 该功能依赖 **Windows 自带 OCR**，需要 **Windows 10 (1809 / build 17763) 及以上**，
  且系统装有**简体中文 OCR 语言组件**（中文版 Win10/11 一般默认自带）
- Windows 7 / 8 / 8.1 上点这个按钮会弹出说明，**其余功能完全不受影响**
- 程序本体仍然是 net40 单文件：.NET 4.0 调不了 WinRT，因此 OCR 通过系统自带的
  Windows PowerShell（`-EncodedCommand`，不落地临时脚本）转一手

### 变更

- 版本号 1.1.0 → **3.0.0**
- 诗词检索底部按钮由「清空 / 开始检索」两个改为「从图片识别 / 清空 / 开始检索」三个

## v1.1.0 — 2026-10-16

界面按安卓版《忘川检索》重做，并把交互细节拉齐桌面习惯。

### 界面

- 整体换成安卓版那套设计规范：宣纸渐变底 + 朱砂主色 + 描金点缀，配色与间距直接取自安卓的
  `colors.xml` / `dimens.xml`
- 左侧竖栏三格导航，图标直接复用安卓的 `vector` 路径（内置一个极简 SVG path 解析器）
- 程序图标改成**圆角正方形**的朱砂方印（安卓那边是圆印，桌面图标用圆角方更合常规）
- 卡片、按钮、输入框、选项卡、条件行全部自绘；**圆角控件四周不再有方角的纸色残余**
  （底色改成沿父链继承，而不是各自重画一遍宣纸底）
- 按屏幕 DPI 整体缩放，200% 缩放下字体、控件、圆角都跟着放大

### 交互

- **弹窗改成标准 Windows 对话框**（固定边框、居中于主窗口、右侧对齐的按钮排布），
  不再是移动端那种自绘居中卡片
- 对话框字号跟随 DPI 缩放（用像素单位的系统字体在 200% 下会小得看不清）
- 去掉自绘的小手光标，改回系统箭头（200% 缩放下小手会被画得很小）
- 鼠标滚轮**跟着光标走**：光标停在哪个可滚动区域就滚哪个，不用先点一下
- 「检索」与「二次检索」变成**一对动作按钮，同一时间只显示一个**：
  还没有上一批结果时显示「检索」，有了上一批结果就收起「检索」、显示「二次检索」；
  点「清空所有」或退回到最初一层时「检索」自动回来
- 一次都没筛出结果（0 条）时仍保留「检索」，免得条件写错后没法直接重搜
- 「清空当前」退回上一级时，会把上一级当时用的条件一并还原（成语回到那 4 个格子、
  名士回到那 9 个条件），界面和结果始终对得上

### 修复

- 诗词字格里的汉字**垂直居中**（单行 TextBox 的文字贴着框顶画，所以要按框高居中摆放，
  而不是靠偏移硬顶）
- 结果区在「二次检索」隐藏时，由两个「清空」键把整行铺满，不再留半截空位
- 名士模块「检索」收起后，省下的高度还给条件列表
- 按钮被隐藏时清掉悬停 / 按下状态（鼠标正停在上面时隐藏，`WM_MOUSELEAVE` 未必送达，
  不清的话下次出现会自带高亮）
- 成语「狗急跳墙」拼音订正为 `gou ji tiao qiang`（题库源文件里曾误写成 `go`，
  导致按拼音搜 `gou` 搜不到）
- **弹窗里的多行文本每行之间都空出一行**：`StringBuilder.AppendLine()` 产生的是 `\r\n`，
  后面又 `.Replace("\n", "\r\n")` 变成了 `\r\r\n`，多行 TextBox 会把 `\r` 也算一次换行。
  现在统一走 `Dialogs.CrLf()` 归一
- **「使用说明 / 关于题库」弹窗按正文实际高度自动撑开**，不再短一截冒出滚动条
- 「关于题库」里的版本号改成从程序集读，不再写死（之前写的是 `v1.1`，改了 csproj 也不会跟着变）
- 「关于题库」里的题库来源只显示文件名，不再把字节数、修改时间这些开发信息摆给用户

### 版权

- 程序内「关于题库」增加**版权说明**段：注明相关知识内容版权归网易所有、
  本程序为非商业同人工具、不含任何游戏美术资源、权利人可联系删除
- exe 的文件属性里也带上了同样的说明（右键 → 属性 → 详细信息）
- 仓库增加 [`NOTICE.md`](NOTICE.md)：逐项说明题库来源、内容性质、不包含什么、不做什么，以及删除承诺

### 工程

- 所有工具脚本去掉硬编码绝对路径，改成以脚本所在位置推算项目根目录，克隆下来即可构建
- 题库源文件收进 `data/`，可用根目录 `bank_src.txt` 指向别处
- 对拍用例从 212 条扩到 **215 条**，并补上整字精确拼音的用例
- `tools/shot.ps1` 增加 `-Dialog`，可以直接抓弹窗窗口，不必整屏截图再裁

## v1.0.0 — 2026-10-13

首个版本。

- 三个模块：成语检索（319 条）、诗词检索（282 条）、名士检索（115 位）
- 题库内嵌进 exe，单个文件绿色免安装，支持 Windows 7 SP1 及以上
- 成语：拼音 / 声调 / 单字三种模式，各 4 个格子，命中位置在汉字 / 拼音 / 声调三处同时标绿
- 诗词：6×5 字格选字成诗，方向键移动，命中格子标绿并标出是诗句里的第几个字
- 名士：9 种检索条件（滚轮选择 + 模糊输入），点结果看详情
- 层级检索：可在一批结果里反复缩小范围，配「清空当前 / 清空所有」
- 内置 `--selftest` 离线自测，与独立的 Python 参考实现交叉对拍
