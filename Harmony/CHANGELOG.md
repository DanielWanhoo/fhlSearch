# 更新记录

## v2.0.0 — 2026-10-16（本仓库首个公开版本）

> 版本号沿用 HarmonyOS 工程开发期的 v2.0.0（v2.0.0 = 加入「名士检索」模块的那一版）。
> Windows / Android 版从 v1.0.0 起算，各平台版本号独立演进。

### 三大模块

- **成语检索**（山石雅集第 14 题）：319 条成语，拼音 / 声调 / 单字三种模式，各 4 个输入格。
  拼音模糊匹配，声调与单字精确匹配；留空的格子表示"这一位不限"。命中的位次会在**成语 / 带调拼音 / 声调**三处同时标绿。
- **诗词检索**（山石雅集第 15 题）：282 条五言诗句，6×5 字格填字，顺序不限，凑成某句诗即命中。
  命中的格子标绿并标上 ①②③④⑤，说明这几个字分别取自哪一格；点结果可切换高亮组合。
- **名士检索**（众里寻他）：115 位名士，9 种条件（朝代 / 爱好 / 社团 / 品阶 / 职业 / 生逢 / 出身·身世 / 技能 / 其他描述）可叠加筛选。
  前四种用系统**「文本滑动选择器」滚轮弹窗**选择，其余为模糊输入；点结果任意一行弹出详情（全部属性 + 题库里属于他的全部相关描述，命中关键词绿色高亮）。

### 检索与层级

- **先填条件、再点检索**：条件行（滚轮 / 输入面板）选完只是记录条件，不会立即检索；
  初始状态点「**检索**」按当前全部条件开始查。
- 「**二次检索**」**在上一次的结果里接着筛**：继续填 / 改条件后点它才生效；没填新条件就点会提示「请先填写新的检索条件」。
- 同一个条件**改选 = 替换**（把「朝代：先秦」改成「朝代：汉」不会变成空集）。
- 「**检索**」键在第一次检索之后自动收起，把位置让给三键；点「清空所有」回到初始状态时自动恢复。
  一条都没命中时「二次检索」仍然在，改完条件直接点它即可。

### 界面与材质

- 底部导航用 HarmonyOS 官方 **HDS（UI Design Kit）「沉浸光感」悬浮页签栏**（`HdsTabs` + 系统材质），滚动时自动收起 / 浮出。
- 玻璃按钮、模式切换分段控件、弹窗关闭键共用同一套材质语言（通体等厚半透明底 + 系统模糊 + 1vp 发丝描边），按下有弹簧回弹动画。
- 中国风配色：宣纸底 + 朱砂主色 + 描金点缀；`base` / `dark` 两套 **21 组**同名同序颜色资源，深浅色自动切换。
- 名士详情弹窗：关键词绿色加粗高亮，「其他描述」每条另起一行并标注题库列号。

### 平板与响应式

- 手机单栏、平板双栏（左条件 / 右结果），中间分栏比例**可拖动**（0.25 ~ 0.75）。
- 平板横屏时悬浮页签栏**水平居中于左栏**，并随分栏比例实时跟随；平板左栏内容靠上对齐、窗口矮时可独立滚动。
- 刘海 / 挖孔、底部手势条安全区四边避让；窗口全屏沉浸（状态栏与导航条透明）。

### 触感

- 名士条件滚轮：滚动换项时轻震一次（系统 Picker 触感）。
- 各页的玻璃按钮（检索 / 二次检索 / 清空所有 / 清空当前 / 清空 / 开始检索）与弹窗关闭键：按下即轻震一次（系统预置触感 `haptic.effect.soft`）。
- 设备能力首次探测并缓存；**没有振动器的设备**（如部分平板）自动静默跳过。

### 数据与脚本

- 三份题库 Excel 放在 `data/`，`scripts/` 下的 Python 脚本把它们转成内嵌 ArkTS 数据；
  重新生成的结果与仓库内文件**逐字节一致**（可复现）。
- 图标由 `scripts/gen_harmony_icons.py` 生成（朱砂圆印 → 分层图标前景 / 背景 + 启动页圆角方图）。

### 已知取舍

- 仓库不放编译好的 hap：HarmonyOS 安装包必须用开发者自己的证书 + 绑定设备的 profile 签名，第三方拿到也装不上。
- 生成的内嵌题库（`entry/src/main/ets/data/*.ets`）**入库**，因此没装 Python 也能直接编译。
