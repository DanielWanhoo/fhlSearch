# 更新记录


## v3.3.0 — 2026-11-01

> 这一版把「好看」和「顺滑」一起收了尾：视觉按华为官方《沉浸光感开发案例》重做，
> 交互补上切页过渡与结果三态切换，最后做了一轮动效审查，把「减弱动画」缺的那块补齐。
> 目标设备是 API 24，官方案例核心的 `uiMaterial.ImmersiveMaterial`（API 26）在这两台机器上看不到效果，
> 所以全部改用 **API 24 可见** 的手段复刻光感：环境光衬 + HDS 材质等级 + 玻璃渐变与反光 + 排版呼吸。

### 一、沉浸光感（视觉层）

#### 环境光衬（AmbientBackdrop）

- 页面底层铺一层**柔光**：左上暖红、右上金、下部青墨，三团大半径径向渐变（静态图层，不参与滚动重绘）。
- 为什么需要它：页签栏与玻璃按钮是「折射背后内容」的材质，纯色底后面没有可折射的东西，玻璃看起来就是一块灰饼；
  垫上光衬之后，玻璃才有方向性的光泽。
- 深浅色各调过两轮：深色首版（红 `#40` + 金 `#33`）叠在纯黑上糊成「脏棕」，降到 `#29` / `#14` 才干净；
  浅色首版顶部偏粉，降到 `#33` / `#29` 回到「暖米色泛一点暖光」。

#### 光感强度（三档材质）

- 「信息」弹窗里新增 **精致 / 均衡 / 柔和** 三档胶囊，直接映射到 HDS 的
  `MaterialLevel.EXQUISITE / GENTLE / SMOOTH`，点选后页签栏材质**立即**变化。
- 选择用 `PersistentStorage` 落盘，重开应用保持上次的档位；正文也补了一节「外观与光感」解释这三档。

#### 视觉与触感

- **输入格**：圆角 8 → **14**，纯色底换成上亮下暗的**竖向渐变**（像一块受光的玉牌），聚焦时四周泛起主色柔光。
- **按钮**：高度 42 → **48**、圆角 21 → 24，顶部加一层渐隐反光，玻璃的「厚」更明显。
- **结果卡**：圆角 12 / 14 → 统一 **18**，阴影更深更散；左侧主色竖线保留（一眼看出结果属于哪一格）。
  刻意**没有**给卡片加反光渐变 —— 成语一次可能出 84 条，每张卡多一层绘制会拖慢滚动。
- **排版**：页面标题 24/600 → **26/700**，副标题贴紧；「检索 N 次」从裸文字改成玻璃胶囊。
- **配色**：`base` / `dark` 两套从 22 组扩到 **33 组**（成对同名同序），新增光斑、输入格渐变、按钮反光、聚焦发光等 token。

### 二、切页过渡（动效层）

#### 背景完全静止、内容走非线性

- 环境光衬 `AmbientBackdrop` 原来由三个检索页各带一份，切页时会随页面被系统整体横向推走；
  现在提到外壳 `pages/Index.ets` 的 `Stack` 最底层（`HdsTabs` 之外），三个页面删掉自己的底衬与外层底色。
- 实测：页签栏上方纯背景带（手机 y2350–2500）切页前后平均绝对差 **0.006~0.09**，同一时刻整图差 ≈13 —— 动的只有内容。
- 内容：`opacity 0.62 → 1` 与 `translate.y 16vp → 0` 由**同一条** `curves.interpolatingSpring(0, 1, 260, 14)` 驱动；
  阻尼比 ζ≈0.43（欠阻尼），落位时越过原位约 **3vp** 再收住，就是肉眼能看到的那点回弹。
- 系统的横向平移仍是 220ms `cubic-bezier(0.2, 0, 0.1, 1)`（本身也是非线性）；只动 `opacity` / `translate`（合成层属性），
  页面结构与既有性能优化全部保留。

#### 进场判断与踩过的坑

- 判断「哪一页是进场页」必须用 `onContentWillChange` 的 `comingIndex`。**不能用 `onChange`**：
  它要等切换动画结束才回调，动画期间 `currentIndex` 还是旧页，按它压暗会把**正在滑出**的旧页压暗（实测旧页亮度 157、新页 227）。
- 淡入起点不用 0：从全透明开始会先黑一下，比硬切更难受；0.62 保留「浮现」感又不会闪。
  最早一版只叠这一层不透明度（200ms `cubicBezierCurve(0.23, 1, 0.32, 1)`），比系统平移略短，滑动结束时内容已经落定。
- **同帧连开两条 `animateTo` 会互相覆盖**：先开淡入再开弹簧，后一条会把前一条的曲线一起接管；改成一条弹簧曲线同时驱动两个属性。
- **`springMotion` 看不到回弹**：实测几乎不过冲（单调回到原位），要肉眼可见的回弹得用 `interpolatingSpring`。
- **底衬留在页面里就一定跟着动**：这不是参数能救的，必须换层级。

### 三、名士详情：卡片形变成弹窗

- 点结果卡不再「唰」地弹出：按被点卡片的实际矩形做形变，关闭时按同一矩形收回；平板按原卡位置展开（起点用
  `ClickEvent.windowX - e.x` / `windowY - e.y`，右栏跨栏也能算对）。
- 弹窗内改成单个 `Scroll` 无极滚动，长描述不再分页。
- 平板弹窗宽度收到屏宽的 **70%**（上限 720 → 504vp），手机仍是 88%。
- 多段描述前加「**其他描述**」二级标题（`DetailPair.section` + `DETAIL_SECTION_H = 38`），与「朝代 / 品阶 / 爱好」等基础项分开。

### 四、识图样图

- 「信息」里的识图样图换成一张纯 6×5 字格图（1256×927，没有界面外框），图注仍是「这种 6×5 字格的图片都能识别」。
  文件名保持 `help_poetry_grid.jpg` 不变，只换内容。

### 五、动效审查与三处整改

- 审查结论：缓动曲线、时长、物理感、性能都是 4 分（满分制），扣分在**无障碍**
  （诗词页 0 处 `isReducedMotion`，三页共用的 `ResultList` 卡片位移也没有门控）与**一致性**
  （条件面板收起的错峰步长 30 / 26 与尾巴 150 都是裸数字）。
- 改动一（无障碍）：诗词页 `onEnterTick()` 在方向判定之后短路，减弱动画时不跑扫光与右栏进场；
  `ResultList` 新增 `cardTransition()`，减弱动画时只留不透明度、不去位移。
- 改动二（一致性）：新增 `PANEL_COLLAPSE_STEP_MS = 26` 与 `PANEL_COLLAPSE_TAIL_MS = 150`，
  成语页与名士页的 `collapsePanel()` 四处裸数字统一走令牌（收起 26ms 比展开的 30ms 略快）。
- 改动三（结果三态）：空状态 / 唯一结果 / 结果列表之间加交叉淡入 `OPACITY.combine(scale({ x: 0.98, y: 0.98 }))`，
  200ms，减弱动画时去掉缩放；卡片逐条错峰出场保留。
- 明确**不做**：「检索 N 次」的数字滚动（功能性数据，一天上百次）、诗词页结构性重排。

### 六、修正与其它

- `floatingStyle()` 的缓存键补上「光感强度」档位：原先切换档位后页签栏纹丝不动（缓存命中，材质参数没重建）。
- 渐变收尾改用「同 RGB、alpha=`00`」的 `*_clear` token（如 `glow_primary_clear`）：
  用透明色收尾是「透明黑」，浅色底上会在光斑边缘留一圈灰雾。
- 诗词 6×5 字格的渐变改挂在外层容器、命中格用透明底，避免命中绿与渐变叠在一起发脏。
- 版本号 **3.3**（versionCode 3500000）。

## v3.2.3 — 2026-10-29

> v3.2 系列（3.2.0 → 3.2.3）是 3.0.0 之后的交互优化：3.2.0 加成语三组输入框、识图先裁后识；
> 3.2.1 把裁剪框比例从锁 6:5 改为自由；3.2.2 结果卡改「一字一列」+ 名士行内输入；3.2.3 加窄屏折叠。

### 成语检索

- **三组条件同时填**（替代原来的「拼音 / 声调 / 单字 三选一」）：声调、拼音、单字各 4 个格子，可任意组合；
  同一位置填了多种需**同时满足**（例：第 1 位声调 4 + 第 2 位拼音 du），整组留空表示这一组不限。拼音仍为模糊匹配。
- **结果卡片改为「一字一列」**：列内自上而下 声调 → 拼音 → 汉字，整排**靠左紧凑**。
  （原来是拼音一行、声调一行、成语一行，且四列均分宽度，字与字之间空隙很大。）
- **窄屏检索后自动折叠输入区**：手机上出结果后，三组输入格收成一行条件摘要（如「第 1 位 声 4 · 第 2 位 拼 du」），
  按键全部保留；点摘要行展开继续改，再点收起。平板双栏不折叠。
  折叠态点「二次检索」会先展开输入区，避免条件没改就空跑一次。

### 诗词检索

- **识图先裁后识**：选图 / 拍照后先出裁剪框，自动框住图中的字格；可拖动移动、拖右下角圆点缩放（比例自由，宽高各自独立、左上角不动），
  **确认后才识别**。混着积分榜、按钮、聊天文字的截图，先裁掉再认能明显减少错字。
- 识别完成后，6×5 表格下方回显**送去识别的那张图**（长边自动缩到 900px），方便核对有没有裁歪。
- 服务层按「裁剪后长边 ≈ 1500px」重新解码，再跑「增强 / 二值化 / 2 倍放大」多轮识别并逐格合并；
  自动框选时先按字框大小滤掉零星小字，再取 4% / 96% 分位，避免框被标题或按钮拉偏。

### 名士检索

- 5 个输入型条件（职业 / 生逢 / 出身·身世 / 技能 / 其他描述）改为**行内输入框**，直接在对应那一行填，
  不再弹 `bindSheet` 面板（平板上那个面板会缩成窄卡片、说明文字被系统关闭键压住）。

### 修正

- **崩溃修复**：`@Component struct` 里用 getter（`private get query()`）在真机上读到的是 `undefined`，
  点「检索」直接 `TypeError: Cannot read property isEmpty of undefined` 退出应用。已改为普通方法 `buildQuery()`；
  同样写法的 `SplitDivider.isActive` 一并改掉（它不崩溃，但条件恒为假、静默失效）。

### 其它

- 版本号 **3.2.3**（versionCode 3200300）。

## v3.0.0 — 2026-10-19

### 新增：识图填字（诗词检索）

- 诗词页新增「识图」：**拍照**或**从图库选图** → 认出图里的 30 个汉字 → 自动填表并检索。
  取图走系统自带界面，**应用不申请相机 / 相册权限**；识别用系统 Core Vision Kit，**全部在设备本地完成、不上传图片**。
- 识别前先做图像增强：灰度 + 对比度拉伸，另一路 Otsu 二值化（对付带花纹的浅色底）；
  再按「增强 @ 原尺寸 / 增强 @ 2 倍（字偏小时才跑）/ 二值化 @ 原尺寸」**逐格投票**，繁体归简后进题库。
  实测 4 张真实游戏截图：由原来的 18~26 / 30 提升到 **30 / 30 全对**，耗时 1~4 秒（多数 1~3 秒）。
- 认出不足 30 个时：已认出的先填上，并在提示里列出「只差一两个字的诗句」（例：`浮云游子意（缺「意」）`），照着补空格子即可。

### 新增：信息页

- 三个检索页**大标题右侧**新增圆形玻璃「ⓘ」按钮 → 居中信息弹窗（88% × 85%，右上角同款玻璃关闭键，正文可滚动）。
- 内容：这是什么 / 题库（**实时条数**）/ 怎么切换模块 / 三个模块的用法（诗词写成 ①~④ 步并**附图**）/
  识图怎么用（**附样图**）/ 清空与返回 / 隐私与权限 / 题库来源与版权。
- 版本号取自应用包信息（`bundleManager`），不硬编码。

### 流畅性

- 去掉诗词页根节点与每个格子的**隐式动画**；`onAreaChange` 加「值没变就返回」；页签样式与悬浮栏材质样式改为**缓存**。
- 手机端不再套「平板几何补偿」的两层容器 + `translate` —— 那层 transform 会把整页变成独立图层，切页时每帧重绘整页。
  实测超过 16.7ms 的帧从 73 / 1351 降到 **2 / 1348**。
- **左右滑动切页改为自实现**（横向 PanGesture，位移 ≥ 60vp）：HdsTabs 自带的拖动过渡会把整页做带透视的斜切，慢拖时看着「一顿一顿」；
  实测这不是掉帧（滑动期间合成器稳定 120Hz）。现在滑动切页走的是和点页签一样干净的横向平移。

### 修正

- CHANGELOG 与说明里「命中格标上 ①②③④⑤」与实现不符（实际只有标绿），已按实际改写。
- 说明正文条目改为整段自然折行（原先手动断句，排出来一行长一行短）。

### 其它

- 新增成对配色 `scrim`（弹层遮罩），配色共 **22 组**、深浅色同名同序。
- 版本号 **3.0.0**（versionCode 3000000）。

## v2.0.0 — 2026-10-16（本仓库首个公开版本）

> 版本号沿用 HarmonyOS 工程开发期的 v2.0.0（v2.0.0 = 加入「名士检索」模块的那一版）。
> Windows / Android 版从 v1.0.0 起算，各平台版本号独立演进。

### 三大模块

- **成语检索**（山石雅集第 14 题）：319 条成语，拼音 / 声调 / 单字三种模式，各 4 个输入格。
  拼音模糊匹配，声调与单字精确匹配；留空的格子表示"这一位不限"。命中的位次会在**成语 / 带调拼音 / 声调**三处同时标绿。
- **诗词检索**（山石雅集第 15 题）：282 条五言诗句，6×5 字格填字，顺序不限，凑成某句诗即命中。
  命中的格子标绿（点结果可切换高亮组合）。
- **名士检索**（众里寻他）：115 位名士，9 种条件（朝代 / 爱好 / 社团 / 品阶 / 职业 / 生逢 / 出身·身世 / 技能 / 其他描述）可叠加筛选。
  前四种用系统**「文本滑动选择器」滚轮弹窗**选择，其余为模糊输入；点结果任意一行弹出详情（全部属性 + 题库里属于他的全部相关描述，命中关键词绿色高亮）。

### 检索与层级

- **先填条件、再点检索**：条件行（滚轮 / 输入面板）选完只是记录条件，不会立即检索；
  初始状态点「**检索**」按当前全部条件开始查。
- 「**二次检索**」**在上一次的结果里接着筛**：继续填 / 改条件后点它才生效；没填新条件就点会提示「请先填写新的检索条件」。
- 同一个条件**改选 = 替换**（把「朝代：先秦」改成「朝代：汉」不会变成空集）。
- 「**检索**」键在第一次检索之后自动收起，把位置让给三键；点「清空所有」回到初始状态时自动恢复。
  一条都没命中时「二次检索」仍然在，改完条件直接点它即可。

### 界面与材质

- 底部导航用 HarmonyOS 官方 **HDS（UI Design Kit）「沉浸光感」悬浮页签栏**（`HdsTabs` + 系统材质），滚动时自动收起 / 浮出。
- 玻璃按钮、模式切换分段控件、弹窗关闭键共用同一套材质语言（通体等厚半透明底 + 系统模糊 + 1vp 发丝描边），按下有弹簧回弹动画。
- 中国风配色：宣纸底 + 朱砂主色 + 描金点缀；`base` / `dark` 两套 **21 组**同名同序颜色资源，深浅色自动切换。
- 名士详情弹窗：关键词绿色加粗高亮，「其他描述」每条另起一行并标注题库列号。

### 平板与响应式

- 手机单栏、平板双栏（左条件 / 右结果），中间分栏比例**可拖动**（0.25 ~ 0.75）。
- 平板横屏时悬浮页签栏**水平居中于左栏**，并随分栏比例实时跟随；平板左栏内容靠上对齐、窗口矮时可独立滚动。
- 刘海 / 挖孔、底部手势条安全区四边避让；窗口全屏沉浸（状态栏与导航条透明）。

### 触感

- 名士条件滚轮：滚动换项时轻震一次（系统 Picker 触感）。
- 各页的玻璃按钮（检索 / 二次检索 / 清空所有 / 清空当前 / 清空 / 开始检索）与弹窗关闭键：按下即轻震一次（系统预置触感 `haptic.effect.soft`）。
- 设备能力首次探测并缓存；**没有振动器的设备**（如部分平板）自动静默跳过。

### 数据与脚本

- 三份题库 Excel 放在 `data/`，`scripts/` 下的 Python 脚本把它们转成内嵌 ArkTS 数据；
  重新生成的结果与仓库内文件**逐字节一致**（可复现）。
- 图标由 `scripts/gen_harmony_icons.py` 生成（朱砂圆印 → 分层图标前景 / 背景 + 启动页圆角方图）。

### 已知取舍

- 仓库不放编译好的 hap：HarmonyOS 安装包必须用开发者自己的证书 + 绑定设备的 profile 签名，第三方拿到也装不上。
- 生成的内嵌题库（`entry/src/main/ets/data/*.ets`）**入库**，因此没装 Python 也能直接编译。
