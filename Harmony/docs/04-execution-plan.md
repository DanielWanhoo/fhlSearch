## 阶段 15：修复「调节分栏比例时页签栏被遮挡 + 右栏显示不完整」✅ 完成（2026-09-10）

**问题**：平板把分隔条拖向左（左栏变窄）后，① 页签栏左边被屏幕边缘裁掉；② 右栏内容被裁掉一半

**根因**：阶段 14 用「整组件 translate 左移 + 内容反向平移」实现居中。`translate` 只改绘制、不改布局盒，组件布局盒仍在原位 ⇒ 页签栏跑到盒外被屏幕裁、内容跑到盒外被盒裁。

| # | 任务 | 状态 |
|---|------|------|
| 15.1 | 改为「**动布局盒**」：盒宽 `L = 2W - 左栏宽`，盒左边缘 `= 左栏宽 - W`（负 margin）⇒ 盒中心 = 左栏中心、盒右边缘 = 屏幕右边缘 | ✅ |
| 15.2 | 内容层改两层结构：外层 `width('100%')` 铺满盒（避免被子组件居中偏移），内层固定窗口宽 + `translate(W - 左栏宽)` 回到屏幕 [0, W]，且恒在盒内 ⇒ 不裁切 | ✅ |
| 15.3 | 胶囊宽度收窄到左栏以内：`wideBarWidth() = clamp(左栏宽 - 24, 200, 520)`（`barWidth` 宽屏三档同值），解决左栏拖窄后页签栏顶出屏幕 | ✅ |
| 15.4 | `SplitDivider` 抽出常量 `DIVIDER_WIDTH = 24`，拖动按「可用宽度 = 总宽 - 分隔条」换算（手指与分隔条 1:1，且与左栏宽口径一致） | ✅ |
| 15.5 | 真机验证：平板 0.5 / 0.30 / 0.25（下限）三档下页签栏均完整可见且居中于左栏、右栏内容完整；手机竖屏布局与改动前一致 | ✅ |
