# 需求规格说明书

## 1. 项目概述

**项目名称**：忘川检索（成语 + 诗词 + 名士检索 APP）
**目标平台**：HarmonyOS NEXT 手机 / 平板
**目标用户**：《忘川风华录》玩家，用于按拼音/声调/汉字检索成语、在 6×5 表格中检索诗词句、按条件检索名士
**当前版本**：v3.0（新增「识图填字」与「信息」页）

---

## 2. 功能需求

### 2.1 底部悬浮导航栏

- 沉浸光感外观（半透明 + 毛玻璃 + 圆角 + 柔和阴影）
- 两个入口：成语检索 / 诗词检索，点击切换
- 顶部状态栏 + 底部导航条做沉浸式处理（内容延伸到系统栏区域）

### 2.2 成语检索

#### 2.2.1 检索模式（三选一）

| 模式 | 用户输入（4 个格子） | 示例 |
|------|----------------------|------|
| 无声调拼音 | 每字的拼音（无音调小写） | an du chen cang |
| 单字声调 | 每字的声调（1~4） | 4 4 2 1 |
| 单字搜索 | 每字一个汉字 | 暗 渡 陈 仓 |

#### 2.2.2 输入规则

- 4 个输入格，对应成语 4 个字
- **允许留空**：留空的格子当通配符，不参与匹配（模糊搜索）
- **拼音模糊匹配**：拼音模式单个格子可填完整拼音（精确匹配）、单个声母（前缀匹配）或单个韵母（后缀匹配），如 `c`、`ang`

#### 2.2.3 检索流程

填格 → 点击「检索」→ 在题库中匹配 → 展示结果

#### 2.2.4 结果分支（三分支）

| 结果 | 展示 |
|------|------|
| 恰好 1 个 | 提示「完成所有检索」+ 成语 + 带声调拼音 + 声调 |
| ≥2 个 | 列表展示所有候选（含拼音/声调）+ 三键：清空所有 / 清空当前 / 二次检索 |
| 0 个 | 提示「未找到该成语」 |

#### 2.2.5 操作键语义

| 键 | 行为 |
|----|------|
| 清空所有检索 | 清空输入 + 历史，回到初始状态 |
| 清空当前检索 | 仅撤销当前这次，回到上一级检索结果 |
| 二次检索 | 在上一次结果基础上再检索一次 |

### 2.3 诗词检索（整合自 PoetrySearch）

- 6×5 汉字填字表格（6 列 5 行，共 30 格），每格一个汉字
- 检索：诗词句所有汉字都存在于表格即匹配（不看顺序/相邻/行列）
- 结果：表格绿色高亮 + 结果卡片（诗句 + 作者 · 篇名）

### 2.4 识图填字（v3.0 新增，诗词检索页）

照搬「搜题软件」的工作过程：给一张题目图片，程序把图里的字认出来、填进表格、直接出结果。

| 项 | 要求 |
|----|------|
| 取图 | ① 相机拍照；② 从系统图库选图。两条路都走系统自带界面，**不申请相机/相册权限** |
| 识别 | 用系统文字识别（Core Vision Kit）提取图中的汉字与坐标；**全部在设备本地完成，不联网、不上传** |
| 还原 | 从一堆「字 + 坐标」里还原 6×5 字格：按纵向重叠归行 → 找最像「5 行 6 列 / 6 行 5 列」的连续几行（列对齐 + 行距均匀）→ 按阅读顺序取字 |
| 填表 | 按阅读顺序填入 30 格（搜索是集合匹配，顺序即位置） |
| 检索 | 认出 30 个字 → **自动检索**；不足 30 个 → 已认出的先填上并提示补全 |
| 容错 | 拍歪/糊/字小可能认错：给出「识别不完整」「已识别但没有匹配，可能识别有偏差」等提示，用户可手动改字 |
| 设备 | 需要设备具备系统文字识别能力；不具备时点「识图」直接提示，不影响手动填写 |

### 2.5 信息页（v3.0 新增）

- 入口：三个检索页**大标题右侧**的圆形玻璃「信息」图标（ⓘ），手机/平板一致
- 形态：居中弹窗（88% 宽 / 85% 高，上限 560×640vp），右上角圆形玻璃关闭键，正文可滚动
- 内容：这是什么 / 题库统计（实时条数）/ 怎么切换模块 / 三个模块的用法（诗词检索写成 ①~④ 步并**附图**）/ 识图怎么用（**附样图**说明「这种字格图能识别」）/ 隐私与权限 / 题库来源与版权
- 参照 Windows 端「使用说明 + 关于题库」两段合并为一段

## 3. 非功能需求

| 项 | 要求 |
|----|------|
| 主题 | 中国风配色：朱砂红主色 + 淡黄宣纸背景 |
| 深色模式 | 支持系统级深色模式，颜色资源成对定义 |
| 多端 | 手机 + 平板，断点响应式布局 |
| 性能 | 检索 1ms 内（千条级题库）；识图识别在设备本地完成，首次需加载识别模型 |
| 离线 | 题库内置、检索与识别全部离线，无需网络 |

## 4. 数据输入

- 成语题库：`data/成语检索.xlsx`（可用环境变量 `FHL_TIKU_SRC` 指向别的目录），格式见 [05-excel-format.md](05-excel-format.md)
- 诗词题库：沿用 PoetrySearch 已有数据（282 条）

## 5. 术语表

| 术语 | 说明 |
|------|------|
| 候选集 | 当前检索范围内可匹配的成语集合 |
| 历史栈 | 逐级检索形成的候选集层级，支持回退 |
| 通配符 | 留空的输入格，不参与匹配 |
| 二次检索 | 在上一轮候选集内继续筛选 |
